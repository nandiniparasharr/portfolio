# Visual archive — "The Ledger" (pre-rebrand)

A complete screenshot record of the site as it stood before the full rebrand,
captured July 2026. Keep this folder untouched so the old design stays
referenceable after the rebrand lands.

## What's here

Filenames follow `{viewport}-{theme}-{page}.png`.

- **Viewports** — `desktop` (1440×900 @1.5x) and `mobile` (390×844 @2x)
- **Themes** — `light` and `dark`
- **Pages** — `home`, `work`, `about`, `contact`, and the four case studies
  (`work-portfolio-prism`, `work-avenue-supermarts`, `work-skippi-ice-pops`,
  `work-the-rebrand`)

Page shots are full-page. The two `about-monitor-*` shots are viewport-sized
captures of the pinned desk scene, which a full-page capture can't show in
both states:

- `about-monitor-lockscreen` — the monitor as it first appears (wallpaper,
  clock, avatar)
- `about-monitor-desktop` — unlocked, with the cascading app windows and dock

## Set pieces worth preserving conceptually

- **Long/Short notepad** (home hero) — two spiral-bound pages, an investor's
  cheat-sheet framing of likes/dislikes
- **Allocation donut** (home) — "inside my brain" split as a portfolio
  allocation
- **Skillset tabs** (home) — browser-tab metaphor over skill groups
- **"On my desk"** (about) — a monitor on a desk running a miniature macOS:
  lock screen, menu bar, draggable Safari/Notes/Word windows, working dock
  with minimize/close and drag-to-trash. The Safari window carries a live
  NSE quote panel fed by `/api/nifty`.
